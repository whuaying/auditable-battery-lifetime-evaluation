# Source access links

These links identify provider or publication access routes. They do not grant redistribution rights. Users must obtain each source under its provider terms.

| Source | Access route | Public-release boundary |
|---|---|---|
| MIT/Stanford/Toyota | [Severson et al. (2019)](https://doi.org/10.1038/s41560-019-0356-8) | Obtain the dataset from the cited source; raw files are not redistributed here. |
| XJTU / PINN dataset | [Zenodo record](https://doi.org/10.5281/zenodo.10963339) and the cited manuscript source | Verify the exact version and terms before download. |
| TJU | [Dataset record](https://doi.org/10.5281/zenodo.6405084) | Use the provider record; raw files are not redistributed here. |
| NASA PCoE | [NASA PCoE data repository](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/) | Obtain directly from NASA; no raw archive is included. |
| CALCE | [CALCE battery data](https://calce.umd.edu/data) and [K2 data](https://calce.umd.edu/data%20II) | Obtain directly from CALCE and confirm redistribution terms. |
| HUST | [Mendeley Data record](https://doi.org/10.17632/nsc7hnsg4s.2) | Use the cited version and its license. |
| ISEA/RWTH P001 | [ISEA battery degradation repository](https://github.com/isea-rwth-aachen/battery-degradation-trajectory-prediction) | Obtain the processed input directly; the 47-to-48 cell crosswalk and upstream processing remain unresolved. |

The aggregate outputs in `data/` are the public analysis layer. Provider archives, cell/cycle-level derived tables, row-level predictions and fit caches remain excluded.
