# Data and code access

This repository is a public code-and-aggregate-results release. Third-party provider archives are not redistributed here.

## Public

- Analysis code, contracts, configuration and dependency locks: `code/`
- Aggregate CSV/JSON results used by the manuscript: `data/`
- Manuscript source/PDF and Supplementary source/PDF: `manuscript/`
- Figures, source maps, manifests and QA receipts

## Restricted or unavailable

- Provider-owned raw archives remain with their original providers.
- Cell- and cycle-level derived tables, row-level predictions and fit caches remain local because redistribution permissions are unresolved.
- A complete end-to-end replay requires obtaining the provider archives and following their access terms.

Source URLs, hashes, parser decisions and release boundaries are documented in the manuscript, Supplementary material, `release_manifest_v6_2.json` and the project audit records. The v6.2 public data/code route is this GitHub repository; a permanent DOI deposit remains pending author and provider confirmation.
